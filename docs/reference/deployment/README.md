**Status:** active stable-reference index
**Coordinate:** `rrflow://rrflow-instance/data/reference-index/deployment`
**Owner:** executable packaging profiles and deployment contracts; linked from `docs/reference/README.md`

Deployment records describe how the same RRFlow authority is packaged. A
packaging profile cannot introduce another engine, database, query planner, or
configuration authority.
