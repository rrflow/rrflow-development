## Before, after and ownership

The prior provider verifier accepted a synthetic summary that declared eight successes although all eight detailed rows were false; repeated labels also passed its two-provider/two-repository length check. The provider runner's `arm` is only a string and successful exit plus substring presence is not an independent correctness oracle. A passing verifier was used by CI on a historical summary that lacks repository identity and raw output per trial. The historical artifact remains unchanged; its earlier recorded results are not upgraded to independently established paired evidence.

This candidate makes the existing evaluation CLI generate an optional bounded, versioned screening summary, recompute outcomes and aggregate counts from retained trial fields, require unique provider/repository/scenario pairs and distinguish unknown provider counters. It rejects contradictory summaries and publishes the limitation that treatment and answer correctness are not verified. CI runs the screening contract tests instead of treating the old historical summary as verified paired evidence. The existing C-07 storage verifier and its fixtures are unchanged. This is an evaluation-boundary repair, not model quality proof, dynamic planning, C-07, J-04 or alpha completion.

Changed: `.github/workflows/ci-reusable.yml`, `crates/evaluation/rrflow-eval/src/main.rs`, `crates/evaluation/rrflow-eval/tests/provider_compatibility.rs`, `eval/README.md`, `docs/poam/rrflow-1.0-alpha/poam-012.md`, the [supporting research](../../../research/rrflow-adaptive-planning-measurement-architecture-research.md), its index, this journal and generated navigation indexes. No source was moved or deleted. The pre-existing historical summary is retained byte-for-byte. The `verify` behavior change is intentional: the previous output called insufficient historical data verified; the replacement keeps that record as history and proves explicit negative behavior. The implementation remains in `rrflow-eval`; no new engine or lifecycle is introduced.
