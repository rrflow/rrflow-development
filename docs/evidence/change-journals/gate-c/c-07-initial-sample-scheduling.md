The expanded PR brief preceded implementation and recorded each fixture correction. This is an installed campaign-driver repair, not a production engine performance change.

`PointRun::segment` keeps its first warmup sample synchronous: the independent evaluator requires that actual ownership baseline before any warmup effect. Later segments start the existing single owned `SampleTask` at or after the original scheduled segment start, overlap it with held-reader setup and scheduled offers, and collect or drain it through the existing bounded task paths. It retains actual observation timestamps, previous in-window samples, reader-open-before-offer ordering, original schedule, attempt ledger, limits, deadlines and error/cancellation propagation. With no carried resource samples, the scheduler anchors its next sampling deadline to the real scheduled segment start; this is a timer anchor, not an invented observation. Missing or delayed actual samples remain subject to the unchanged independent resource coverage validator. Native sampling may still compete with the engine, and slow held-reader setup or real sampling gaps can still fail the workload.

The added case in `sustained::installed_capacity_workload_smoke` uses a real installed primary and a later measured segment with a held initial-sample gate and a real held reader. Before the change, the exact ignored test failed `initial sample completed before its gate`: the unconditional synchronous initial sample had already produced a Resource event. With the candidate, an actual acknowledged operation and its matching independent present readback completed while the sample remained held; after release the actual sample and held-reader observation were retained, the reader enclosed that operation, and `validate_segment` passed. Clearing the recorded resource samples from a cloned segment then produced the existing `segment evidence missing or exceeds bound` error. The first warmup baseline remains synchronous, and the existing periodic-sample/native-worker hold, cancellation, restart and joined search portions of the smoke ran unchanged.

Intermediate test failures are retained here. The first changed fixture used sequences 0?5, which contained no writes and therefore could not activate reader interference; using 15?19 supplied writes without the sequence-14 backup. The next validation failed `host ceiling exceeded` because this synthetic smoke fixture declared only 512 MiB for a real shared host; the test-only allocation and storage budget were bound to the host's actual nonzero total physical memory. The fixture then failed a 1 MiB retained-owner ceiling; observed sample values were 4,448,837, 2,811,184 and 2,822,556 bytes. Giving it the entire 256 MiB process budget failed pre-admission because other memory reservations also need space, so this one nonqualification fixture uses an explicit 16 MiB retained budget within its existing process reservation. A separate `reader interference lies outside its segment` failure exposed a test clock younger than the three-second sequence offset; using an explicitly aged clock preserves the intended schedule. No frozen campaign, installed configuration or acceptance threshold changed.
