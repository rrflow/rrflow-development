The analyzer reads bounded numbered segments and conflict stderr, requires one campaign digest, correlates the trace's synthetic-ID hash with the hashed retained logical ID, and considers overlapping client intervals within the same operating point and seed. It returns hashed identities, source file digests, cursor observations, bounded overlap lists and explicit unmatched or rejected-without-trace counts. It preserves `uncertain` as observed. Thirty-two trace entries, 100,000 attempts, 4,096 segments, per-file and total byte ceilings, and a 64-row overlap output cap bound work; truncation is reported. A reported overlap does not prove the internal conflict branch, commit order, or causation. Segment hashes are reported for reference and are not verification of a hash chain.
