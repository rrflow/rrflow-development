## Behavior and first failure oracle

A tracked file edited twice while still reported modified produces two source
identities. The observer binds HEAD, branch/status/diff/context digests, its own
source/helper bytes and Python version. It requires two equal sequential reads,
defers moving/invalid input and can recover after a subsequent edit. It never
claims an atomic engine source stamp. Repeated unchanged polls, including after
restart, do not duplicate records; returning to a previous state after another
observation is a new linked transition.

Retained logs preserve record digests and predecessor order under an exclusive
append lock. Partial tails, edits, reordered chains, occupied locks and budgets
fail before append. Raw diffs are not exported. Pattern redaction is best effort,
and trusted local Git configuration is a prerequisite rather than an adversarial
process sandbox. Every record remains unreviewed, training admission false,
engine receipt null and outcome unknown. A reported override is not a label.
