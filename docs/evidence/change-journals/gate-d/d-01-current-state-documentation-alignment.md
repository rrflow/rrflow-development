Before edits, exact search found all planned contradictions, including
`incorrectly derives`, `There is no accepted alpha bootstrap command yet`,
`Gate C-03 owns the target`, `C-03 must commit`, `current reads may reconstruct`,
`C-02 through C-04: prove`, and `structurally wrong` in present-tense reference

The first post-edit oracle did not pass. Three authoring defects were exposed and
corrected:

1. the first invocation placed Markdown backticks inside a Bash double-quoted
   Python program, so Bash attempted command substitution for `local_daemon`
   and `remote`; subsequent execution used single-quoted source or the planned
   command's parsed argument vector with `shell=False`;
2. README lacked the exact explicit phrase `D-01 remains open`, and the oracle's
   contiguous lowercase `accepted C-04` marker was absent even though the prose
   used `Accepted C-04`; both were made explicit; and
3. an overlapping patch left a duplicated `promise.` fragment and the stale
   `Gates C-03, H-04, and J-01` line in the server reference. The expanded exact
   search caught it, the complete paragraph was reread, and it was replaced
   with the remaining H-04/J-01 ownership.

The final oracle rejects every frozen stale phrase and requires explicit
open-D-01, accepted-C-03, and accepted-C-04 language. The wider stale-language
search returns no match.
