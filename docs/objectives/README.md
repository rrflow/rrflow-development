# RRFlow objectives

**Status:** active objective index
**Coordinate:** `rrflow://rrflow-instance/data/objective-index/rrflow-objectives`
**Owner:** measurable outcome discovery; linked from `docs/README.md`

An objective defines a result and the evidence required to call that result
real. It does not prescribe implementation order; the roadmap owns that. It
does not track deficiencies; the POA&M owns that.
