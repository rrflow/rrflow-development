# .ai

Working records for AI-assisted engineering on this repository. They are plans and lessons, not product documentation and not an authority: `AGENTS.md` and the owner records it names still decide.

| File | What it is |
|---|---|
| [lessons.md](lessons.md) | What went wrong in earlier sessions and the rule that replaces it. Read before planning. |
| [plan-engine-restructure.md](plan-engine-restructure.md) | The active plan: the target workspace, the audit behind it, the phases, and the state of each. |

A plan file is updated in the same commit as the work it describes. When a phase is finished its row says so with the commit; nothing is marked done from memory.
